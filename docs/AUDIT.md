# Аудит и план улучшений PHOTO ID

Дата: 8 октября 2026. Ветка: `improve/site-quality`.

## Контекст и решение

Сайт — статический HTML/CSS/JavaScript: главная `index.html` и полный прайс `price.html`. Нет package.json, backend, форм, сборщика, CI и настроенных тестов. Сценарий: посмотреть примеры и цены, связаться со студией по телефону или в мессенджере. Сохраняем маршруты, услуги, цены, контакты, реальные фотографии и голубой акцент.

Выбран вариант точечного улучшения существующих страниц: единые CSS-токены, исправление интерактивных элементов, адаптивные композиции, оптимизированные копии изображений. Переход на фреймворк, новая UI-библиотека и backend не нужны: увеличили бы сложность без пользы для текущего сценария. CSS остаётся готовым для статического хостинга; `scss/style.scss` синхронизируется с основной таблицей стилей.

## Что уже хорошо

- Реальные примеры обработки, понятные пакеты услуг и подробный прайс.
- Русский язык, контактные данные, карта, телефон и мессенджеры.
- Семантические секции, базовая адаптивность, lazy loading части галереи.
- Фирменный голубой цвет и узнаваемый логотип.

## Исходное измерение

Chromium, 1440×1000, localhost, внешние запросы блокированы для воспроизводимости. Одно измерение, без ограничения CPU/сети: главная — 70 161 348 байт ресурсов, LCP 1756 мс, CLS 0; прайс — 244 374 байта, LCP 308 мс, CLS 0. Axe выявил недостаточный контраст у 7 элементов главной и 1 элемента прайса. Эти значения не являются полевыми Core Web Vitals.

## Ограничения выпуска

Проверить права на портреты, фактические цены, формулировки о требованиях к документам и действительность внешних контактов должен владелец. Существующие шрифты имеют Trial в названии: в обновлённом UI используется системный стек, они не загружаются. Деплой, production-конфигурация, БД и секреты в эту работу не входят.

## Выполненные изменения

- На двух страницах сохранены фирменный голубой цвет, маршруты и контакты; обновлены масштаб заголовков, отступы, кнопки, карточки, плотность и адаптивные сетки. Hero больше не выходит за колонку. Планшет использует свою композицию, прайс имеет навигацию к категориям.
- У меню есть Escape, изоляция фона, цикл фокуса, восстановление фокуса и сброс при изменении ширины. FAQ сообщает раскрытие и скрывает закрытые ответы; ответы не обрезаются фиксированной высотой. Сравнение поддерживает Home/End, стрелки, мышь и touch; исправлен переход от значения 0.
- Галерея показывает фотографии целиком в оформлении отпечатков. Нет дублирующих клонов. Есть нативная touch-прокрутка, drag мышью, кнопки, номер текущего фото и индикатор. Нативный `dialog` открывает крупное фото, поддерживает стрелки/Escape, ошибки загрузки и возврат фокуса. Без JS ссылки открывают реальные файлы.
- Созданы 22 WebP-копии размером 1 493 186 байт суммарно; исходные фотографии (67 726 918 байт для используемого набора) не изменялись. Responsive images выбирают нужный размер, картинки имеют размеры, галерея и сравнение загружаются лениво.
- По пожеланию владельца видео автоматически играет фоном без кнопки управления. Загрузка начинается только в видимой секции; вне экрана, при скрытии вкладки и при prefers-reduced-motion воспроизведение останавливается. При ошибке остаётся постер. Отзывы загружаются по приближению, имеют loading/error/retry. Сохранены действующий ID SmartWidgets и карта. Реальные отзывы проверены отдельно; исправлены их контраст, отсутствующие alt и обрезанные тексты. Маркировка провайдера сохранена.
- Убраны внешние шрифты, постоянный параллакс, tilt, анимированные счётчики, стеклянные слои, мерцающие градиенты и скрывающее содержимое reveal. Добавлен заметный focus. JS работает без дополнительных библиотек приложения.

## Что остаётся перед публикацией

- Проверка Safari/Firefox, физических устройств, screen reader и полноценный ручной аудит WCAG.
- Непрерывное фоновое видео оставлено без кнопки по пожеланию владельца. Для полного соответствия [WCAG 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) требуется доступный способ остановить или скрыть движение дольше 5 секунд; текущая поддержка reduced-motion и остановка вне экрана не заменяют этот критерий.
- Полевые LCP/INP/CLS на реальном хостинге, с HTTPS, кешированием и внешними сервисами. Работу самого iframe карты и внутренние всплывающие окна провайдера нельзя считать полностью проверенными axe-аудитом наших страниц.
- Контроль действительности выездной цены и бизнес-формулировок владельцем; цены полного прайса уже обновлены по переданному SVG.
- Локальные артефакты проверки находятся в `.audit` и не добавлены в Git.

На момент завершения локального аудита коммит и деплой не выполнялись; публикация выполняется отдельно по поручению владельца. Изменений production-конфигурации, БД, секретов или прав доступа нет.
